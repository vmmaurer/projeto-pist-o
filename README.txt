REPROJETO DO BOWL DO PISTÃO — SITE 3D TOUCH

Conteúdo pronto para hospedagem.

Estrutura obrigatória:
  index.html
  styles.css
  app.js
  models/piston_original_web.glb
  models/piston_proposed_web.glb

IMPORTANTE: envie a pasta inteira mantendo a pasta models e seus dois arquivos GLB.
Não altere os nomes dos arquivos.

Não exige Node.js, Python ou servidor local. O navegador carrega os GLBs diretamente do caminho relativo /models/.

Funcionalidades: rotação por toque/arraste, zoom, pan, vistas 3/4/topo/lateral, reset, rotação automática, modo original/proposto/comparação e painel do bowl.
